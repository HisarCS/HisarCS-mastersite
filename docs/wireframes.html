Open issues (found by this audit, not yet fixed)

  • OPEN Member cards: name/meta not line-clamped — a long name breaks row-height uniformity (apply the §03 fixed-budget pattern).
  • OPEN Person page field chips are solid-ink pills — inconsistent with the §F tag system; unify when tags become clickable site-wide.
  • OPEN Entry-page member avatars use a legacy char-code hash for color; tags already use hashStr — the same person can differ in color between the pixel wall and an entry roster.
  • OPEN ResearchView.module.css still carries a legacy 560px breakpoint (system is 640/900) — migrate when touched.
  • OPEN Curated authors: [] arrays in lib/data/research.ts are still empty.
  • OPEN stat.jpg (About) is source-limited at 1226px.
